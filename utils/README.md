# Mock Transmitter
A simulated MCU transmitter. It generates oscillating sensor data (12 channels), packs it into a MessagePack dictionary, frames it with COBS, and transmits it over a serial port.

To test the scripts without physical hardware, you need `socat` to create virtual serial loopback devices.

```bash
sudo pacman -S socat
```

### Step 1: Create the Virtual Serial Link
In a terminal, run `socat` to create a pair of linked pseudo-terminals (PTYs).

```bash
socat -d -d pty,raw,echo=0 pty,raw,echo=0
```
*Note the output. It will assign two ports. Leave this running.*

### Step 2: Start the Receiver
In the same terminal, start the receiver script, pointing it to the **first** port. Remember, you can use verbose mode to see what's going on.

### Step 3: Start the Transmitter
In another terminal, start the mock MCU script, pointing it to the second port generated by `socat`.

```bash
python3 mock_tx.py -p <second socat port>-v -r 10
```
*Options:*
    - `-p, --port`: Serial port to transmit on
    - `-b, --baud`: Baud rate (default: `115200`)
    - `-r, --rate`: Transmission rate in Hertz (default: `10.0`)
    - `-v, --verbose`: Verbose output
    - `-d, --debug`: Enable logging (prints raw hex bytes)
